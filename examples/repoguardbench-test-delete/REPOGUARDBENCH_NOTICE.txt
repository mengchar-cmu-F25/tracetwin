TraceTwin contains adapted projections of six records from
results/scored/main.jsonl and references three records from
data/repoguardbench_core.jsonl. The projections retain selected logged
turn/action/effect fields, add TraceTwin step IDs and observed markers, and add
one explicit clean-side no-op where the source clean run ended one turn sooner.
The offline oracle narrowly reimplements the MIT-licensed TEST_DELETE branch
used to compute unsafe_action_landed and maps the last retained recorded test
report to the official utility_pass input for the benign side.
